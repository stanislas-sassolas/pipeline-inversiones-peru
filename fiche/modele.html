Pour suivre un projet
  • Fiche d'un projet : consultation des investissements du MEF (Invierte.pe), avec le code CUI.
  • Marchés publics (études, travaux, supervision) : SEACE, la plateforme des achats de l'État.
    • $proinversion
  • Ce sont des marchés de conseil, pas les appels d'offres des PPP.
  • Carte et méthode : stanislas-sassolas.github.io/pipeline-inversiones-peru

Sources. MEF, Banco de Inversiones, fichier DETALLE_INVERSIONES (données ouvertes), version du $date, archivée chaque jour depuis le 13/11/2026 ; BCRP, série PN01207PM ($periode_taux : 1 US$$ = $taux3 S/) ; ProInversión, investinperu.pe, consulté le $date_proinversion.

Méthode et limites. Investissements publics actifs de 100 M S/ ou plus, doublons de code retirés. Coût = coût actualisé + contrôle de la Contraloría (organe de contrôle de l'État), publié à part par le MEF. Stade d'après les formatos 8 et 9 ; un seul mode par projet. Coûts pluriannuels indicatifs ; dépense de l'année partielle jusqu'en décembre. Le fichier ne contient ni les projets privés (mines), ni les PPP autofinancés. Totaux arrondis.

Mots du MEF. Budget de l'année : PIM ; dépense : devengado ; études détaillées : expediente técnico ; CUI : code unique d'investissement ; programme multiannuel : PMI ; PPP : APP en espagnol (asociación público-privada) ; travaux contre impôts : obras por impuestos. Note produite par un pipeline de données en Python ; Stanislas Sassolas, élève-ingénieur (CPE Lyon), projet personnel sans lien avec aucune administration.
